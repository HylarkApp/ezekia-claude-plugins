# Meeting Prep

Using the Microsoft 365 connector, find the meeting referenced in context
on the calendar. Cross-reference attendee email addresses against Ezekia —
person record, and any projects they're a contact on. Prepare a concise
brief: key project status/concerns, open action points, and one icebreaker
topic grounded in real context (a recent note, shared interest, or project
milestone — not generic small talk).

Keep it tight — this is a pre-call skim, not a full account history. Output
via the visualizer.
